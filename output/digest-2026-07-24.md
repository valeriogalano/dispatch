- [`0d0d391`](https://github.com/valeriogalano/Timebox/commit/0d0d391ede378705718d75e8714605e000532c5a) fix(todoist): accept API v1 due.date datetimes in sync filter
  Todoist API v1 dropped the legacy due.datetime field: timed tasks now
  carry the time inside due.date ("YYYY-MM-DDTHH:MM:SS"). The sync filter
  required due.datetime and silently discarded every fetched task, so the
  app showed zero Todoist tasks despite a working token. Accept both shapes.
