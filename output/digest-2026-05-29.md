## KeepInTouch

### Added
- `fc63924` feat: per-contact reminder thresholds
  Add ability to override the two global reminder thresholds on a per-contact
  basis. Custom values are stored in the contact's address book entry via
  CNContactRelations (as string-encoded integers) so they sync alongside the
  contact and survive uninstall/reinstall. A local UserDefaults cache mirrors
  the values for fast reads.
  
  Each threshold can be reset individually to the global default; when both
  match the defaults, the custom record is removed from the address book. The
  contact detail screen exposes a native Stepper for ±1 adjustments and a tap
  on the value opens a native alert with a number field for direct entry.
