### Fixed
- [`7bb47da`](https://github.com/valeriogalano/KeepInTouch/commit/7bb47daf3b3b47d2cd53bef647f1af5cc5acb68d) fix: fix contact picker UI and search on macOS
  Replace .searchable (unreliable inside a sheet on macOS) with an
  explicit TextField. Load all contacts once on sheet open and filter
  in memory by case-insensitive substring on each keystroke, avoiding
  per-keystroke enumerations and race conditions.
  
  Add a minimum frame to the sheet so the list is usable, and apply
  .buttonStyle(.plain) + .listStyle(.plain) to rows so they render as
  standard list items rather than bordered buttons.
- [`2bf17ea`](https://github.com/valeriogalano/KeepInTouch/commit/2bf17eadc9b4eba2df152fb6430e74f8dc6eb750) fix: replace close icon with 'Chiudi' button in macOS Settings
- [`3a28971`](https://github.com/valeriogalano/KeepInTouch/commit/3a28971efed8e2a3dcbfcc9aa12564c1ea610e98) fix: make contact picker search work on macOS
  The macOS contact picker showed no results because
  CNContact.predicateForContacts(matchingName:) does not work when
  combined with unifyResults = false (required to avoid the sandbox
  "unentitled notes" error during contact unification).
  
  Replace the broken predicate with a single full enumeration on sheet
  open, filtered in memory by case-insensitive substring on each
  keystroke. This also gains substring matching (e.g. "ari" -> "Mario")
  instead of the predicate's word-prefix-only behavior.
  
  On macOS the sheet now uses an explicit TextField for search (the
  .searchable modifier inside a sheet on macOS frequently fails to
  display or receive focus) and a minimum frame so the list is usable.
