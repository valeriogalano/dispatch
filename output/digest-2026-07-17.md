- `819d312` fix(isbn-scan): add manual capture, macro camera selection and focus tweaks
  The ISBN scanner previously had no shutter button and relied solely on
  continuous metadata detection, which often missed small book barcodes.
  Add a capture button that analyzes the current video frame with Vision,
  let the user switch between the standard and ultra-wide (macro) camera,
  configure near-range continuous autofocus, and limit detection to the
  central scan guide so both automatic and manual scans work better.

  Google Books API occasionally returns 503 Service Unavailable. Add a
  small retry loop with exponential backoff (up to 3 attempts) for transient
  5xx responses, while still failing immediately on 401/403 unauthorized.
