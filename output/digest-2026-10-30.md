### Added
- [`b24d003`](https://github.com/valeriogalano/Timebox/commit/b24d003fe71a71d580420266029cbf9977d3ad78) feat: warn in Settimana when the plan pushes an area past its weekly limit
  The weekly-limit banner fired only once the done hours were over the cap.
  weeklyLimitsAtRisk (week-forecast.js) also flags areas whose Previsto
  exceeds the limit while the done hours still fit, so the warning arrives
  while planning. AGENTS.md documents the forecast rule; CHANGELOG lists the

- [`57b8371`](https://github.com/valeriogalano/Timebox/commit/57b8371cd2251444e604675d2fcf3e7c91b88f24) feat: per-week plan marks and weekly limit line in the Trend mini charts
  The dashed line used the selected week's plan for all eight weeks while the
  subtitle called it the template rate. Each bar now carries its own week's
  plan. The glyph sums the closed weeks only, so the week in progress no longer
  reads as under plan. Areas with a weekly limit get a limit line and a count
  of the closed weeks that ended over it, for the monthly cap check.
- [`f8151bf`](https://github.com/valeriogalano/Timebox/commit/f8151bff1b11ecd8fc72487ebc9f3cdeab5b8b18) feat: judge the Settimana lens on the forecast
  Mid-week the done hours against the whole week's plan always read "under":
  on 15/10 INVALSI showed a deficit while heading 2h past its limit. The load
  card, the per-area table and the weekly limits now judge the Previsto
  (weekForecast), which equals the done hours once the week is closed.
  
  - Carico: percentage, glyph, status and delta on Previsto; the run-rate
    projection is gone (it counted the weekend and ignored the plan).
  - Per area: Piano, Fatto, Previsto; Extra, delta and Limite columns removed,
    the delta moved to the glyph's tooltip.
  - Limiti della settimana: the warning fires when Previsto exceeds the cap,
    with the margin in its tooltip.
  - Fatturabile a consumo: projection is billable done + remaining plan,
    instead of max(done, plan) per area.
  - Budget totali leave this lens: In prospettiva already lists the same caps.
- [`8afdb71`](https://github.com/valeriogalano/Timebox/commit/8afdb713013dc6e19f177dfd2d69e90081f1e9c0) feat: add the week forecast (Previsto) as a shared pure module
  weekForecast counts what is done before today and, from today on, at least
  the plan (or what is already logged, if more). Today therefore includes its
  remaining plan. forecastUsage applies the remaining plan to a weekly cap on
  both worked and billable hours. The CommonJS twin in lib/domain.js lets the
  CLI and MCP use the same rule later.
- [`961d37a`](https://github.com/valeriogalano/Timebox/commit/961d37ae4629224e4a443959183d82fa53d3e3f4) feat: show only repeated overrides that matter, largest first
  The Override ripetuti list showed every slot corrected in 3 of the last 8
  weeks, in day order, so a fixed 3h gap was lost among quarter-hour noise.
  An average gap now has to exceed the same tolerance as the Andamento glyphs
  (TOL_HOURS or TOL_PCT of the slot's template, whichever is wider), and the
  list is sorted by size. The per-day headers went away with the day order;
  the day is part of each row.
- [`3f373a7`](https://github.com/valeriogalano/Timebox/commit/3f373a738bedfc53344862afb44870afb377a646) feat: add hours in another slot from Giorno -> Ore
  A project with hours in one slot had no row to log hours in a different slot
  of the same day, so a past day could not be completed. The last row of each
  project now has a + that lists the slots still free and adds an empty row
  there; saving goes through the existing planDayEntrySave. freeEntrySlots in
  dayPlanning.js decides which slots are offered.
