# Aggiornamenti manuali

Qui finisce ciò che non ha un commit dietro: un episodio del podcast, un articolo,
una release, una cosa fatta e non tracciata in git.

Un file per giorno, nominato con la data in cui la cosa è avvenuta:

```
manual/2026-07-24.md
```

Dentro si scrive in testo libero, come si scriverebbe a una persona. Il contenuto
non finisce nel recap così com'è: `collect.py` lo accoda al digest sotto
`## Aggiornamenti manuali` e l'IA lo interpreta insieme ai commit.

Vengono raccolti solo i file la cui data cade nella finestra del digest. I file
restano qui dopo la pubblicazione: sono l'archivio di ciò che git non sa.

Questo README è ignorato: non ha una data come nome.
